Line icon from Lucide (CDN) or the ndea custom set; use for compact controls where words would crowd a tile header.
```jsx
<Icon name="settings-2" />
<Icon name="nd-legend" size={15} />
```
- Custom names start with `nd-` and are drawn on Lucide's 24px grid.
- Keep stroke 1.5 at 13–15px. Color inherits from text.
