Design rationale
Trigger parity: visually identical to the existing Combobox trigger — drop-in replacement. The source type is only revealed as a small badge suffix, not cluttering the trigger when not needed.

Unified search: typing simultaneously narrows both obs columns and gene groups. Users who know a name but not its type don't need to pick a mode first — the result appears in the right group. This is the least friction path for exploratory use.

Layer chips: materialise as an inline chip row at the popover footer only when a gene is selected. Chips are always visible (not hidden in a dropdown), enabling single-click layer switching without any secondary opening.
Best for: the most common case — a user who doesn't have a preformed "I want a gene" vs "I want obs" mental model, just wants to type a name and pick it. The unified search surface scales cleanly to 33k genes because only matches are shown.
