Design rationale
Source badge: acts as a 3-state cycle button (none → obs → X → none). One click always tells you the mode and lets you change it without opening any panel.

Value combobox: only appears once a source is set. Contents change contextually — obs columns list or gene search. The pill never overflows because the value trigger truncates.

Layer token: appears inline only when gene+value are both set. Its visual style (green border matching the gene badge) reinforces that it belongs to the gene selection, not the obs selection.
Best for: power users who quickly cycle modes. The badge is a persistent, one-click affordance rather than requiring menu opening. The in-pill layer token keeps everything visible at once without opening secondary panels.
