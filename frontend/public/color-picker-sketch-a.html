Design rationale
Trigger: a single compact token — source badge + value label + chevron — fits naturally in the existing glass pill row without expanding it. The badge color (blue for obs, green for gene) gives immediate context at a glance.

Popover: two tabs cleanly separate the two mode domains. Obs uses a flat search list (~500 items). Gene tab uses debounced server search (not prefilled) with a "none / clear" shortcut. The layer picker only materializes when a gene is selected — no wasted vertical space otherwise.

Gene list: rendered lazily — only top 50 shown by default; user types to search (debounced 200ms → GET /api/var/names?q=…&limit=50).
Best for: users who think in terms of distinct modes (obs vs gene). Clear switching prevents accidental cross-type selections. The layer picker being contextual avoids showing irrelevant controls when not needed.
