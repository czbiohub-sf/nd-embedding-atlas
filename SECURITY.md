# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please do not open a
public issue. Responsibly disclose it by contacting
[security@chanzuckerberg.com](mailto:security@chanzuckerberg.com).

Include enough detail to reproduce and assess the issue, but do not include
sensitive information beyond what is necessary. The security team will
coordinate triage and next steps with the project maintainers.
